Disk Flashlight отображает отсканированный каталог в виде секторной диаграммы (sunburst): текущий каталог находится в центре, каждое следующее кольцо содержит дочерние элементы предыдущего, а внутри кольца элементы упорядочены по размеру: самые крупные идут первыми по часовой стрелке от двенадцати часов.

![Disk Flashlight: диск C: в виде секторной диаграммы, слева дерево каталогов](images/screenshot.png)

Проект написан на Rust и использует [egui](https://github.com/emilk/egui) с backend wgpu.

## Основное

- **Быстрое сканирование.** С правами администратора тома NTFS читаются непосредственно из главной файловой таблицы (MFT): диск `C:` примерно с 920 000 объектов сканируется менее чем за секунду.
- **Отзывчивая диаграмма.** Диаграмма рисуется одним кэшированным GPU-mesh и остаётся плавной на деревьях из миллиона объектов и при 200-кратном увеличении.
- **Поиск, типы файлов и крупные файлы** рядом с диаграммой и в связке с ней: совпадения и типы выделяются цветом на диаграмме, а любой список ведёт в папку элемента.
- **Очистка на месте.** Элементы перемещаются в корзину с диаграммы или из любого списка, и вид обновляется без повторного сканирования.
- **Экспорт в CSV** дерева, списков и результатов поиска — из окна или из командной строки.
- **Русский и английский** интерфейс, светлая и тёмная темы, портативный режим; обращение к сети ограничено сканируемыми сетевыми путями и необязательной проверкой обновлений.

| Файл | Описание |
|---|---|
| `Disk_Flashlight_<версия>_Setup.exe` | Установщик для текущего пользователя. Права администратора не требуются: программа помещается в `%LOCALAPPDATA%\Programs\Disk Flashlight`. Дополнительная задача установщика добавляет пункт **Анализировать в Disk Flashlight** в контекстное меню Проводника для папок и дисков; при удалении программы пункт удаляется. |

Исполняемые файлы не подписаны, поэтому при первом запуске Windows SmartScreen может предупредить о неизвестном издателе.

## Возможности

### Сканирование

- **Сканирование через MFT.** При запуске с правами администратора NTFS-диски и папки сканируются чтением главной файловой таблицы напрямую (диск `C:` примерно с 920 000 объектов сканируется менее чем за секунду). Папка выделяется из таблицы всего тома, поэтому даже небольшая папка сканируется примерно столько же, сколько её диск. При сканировании через MFT жёсткие ссылки учитываются один раз, в папке первого имени файла, а системные области, такие как `System Volume Information` и метафайлы NTFS, включаются в результат.
- **Обход каталогов.** Тома без NTFS, сетевые пути и запуск без прав администратора обслуживаются параллельным обходом каталогов (тот же диск `C:` сканируется около 8 секунд на холодном кэше и около 1,3 секунды на прогретом). Сетевые диски и тома с другими файловыми системами MFT не поддерживают и всегда сканируются этим способом.
- **Быстрый скан.** Без прав администратора на панели инструментов всегда есть кнопка **Быстрый скан** (отмечена щитом UAC): она перезапускает приложение с повышенными правами, после чего локальные диски NTFS сканируются через MFT. Если диск или папка на таком томе уже выбраны, они сразу сканируются заново.
- **Ошибки доступа.** Папки, которые обход каталогов не может прочитать (обычно из-за нехватки прав), подсчитываются в строке состояния; число является ссылкой на окно **Ошибки доступа**, где перечислены их пути с причиной, список можно скопировать или сохранить в CSV (**Экспорт…**, столбцы `path` и `error`), а из контекстного меню открыть расположение папки в Проводнике.
- **Метрика размера.** Диаграмма измеряет физический размер (с округлением до кластера, с учётом сжатых и разреженных файлов; небольшие файлы, которые NTFS хранит внутри их записи MFT, места не занимают) или логический.

### Диаграмма

- **Кольца.** По умолчанию семь колец, отрисовываемых одним кэшированным GPU-mesh; сектора тоньше одного пикселя не создаются, поэтому отзывчивость не зависит от размера дерева. Число колец, от 3 до 12, выбирается в списке **Колец** на панели инструментов или клавишами `+` и `-` и сохраняется между запусками; к краю кольца становятся тоньше, так что внешнее примерно вчетверо тоньше первого при любом их числе.
- **Файлы и папки.** Как в OverDisk, файлы рисуются с зазором от своей папки, поэтому сразу отличаются от каталогов. Края сглаживаются 4-кратным мультисэмплингом.
- **Мелкие элементы.** Элементы, слишком мелкие для различения (дуга менее примерно четырёх точек), объединяются в каждом каталоге в один нейтральный сектор **N мелких элементов**; при увеличении группа распадается по мере того, как элементы становятся достаточно широкими, а щелчок по группе увеличивает диаграмму.
- **Свободное место.** Если сканируется целый диск (или сетевой ресурс) и в центре находится его корень, свободное место показывается бледным серо-голубым сектором после содержимого в первом кольце; в подсказке указаны его размер и доля от ёмкости.
- **Подсказка.** Для сектора под курсором показываются имя, логический и физический размер, доля в родительской папке и в центре диаграммы (`12% of Users, 3.4% of C:`), число каталогов и файлов, а также дата последнего изменения — в виде даты и возраста (`2024-03-15 (6 months ago)`). Датой файла считается время последней записи в него; датой папки — самое позднее время записи среди всего, что в ней находится, поэтому папка со старыми файлами остаётся старой, даже если в неё недавно добавили элемент.

#### Цветовые схемы

Схема выбирается на панели инструментов.

| Схема | Цвет |
|---|---|
| **По размеру** | Наибольший элемент среди соседей красный, меньшие смещаются к жёлтому, а к краю диаграммы цвета бледнеют (как в OverDisk). |
| **По уровню** | Цвет зависит от кольца. |
| **По возрасту** | Цвет зависит от даты последнего изменения: от красного для элементов, изменённых незадолго до сканирования, через жёлтый и зелёный к синему для элементов старше десяти лет, по логарифмической шкале, которую поясняет легенда в углу диаграммы. |
| **По типу** | Каждый из двенадцати самых объёмных типов файлов скана получает свой цвет, все остальные файлы — один нейтральный, папки при этом серые; цвета не меняются при переходе между папками, а легенда в углу перечисляет их. |

### Навигация и действия

- **Навигация.** Щелчок по сектору каталога делает его центром, а по файлу — переходит в его папку; щелчок по центру поднимает на уровень выше. Навигация назад, вперёд и вверх сохраняет историю.
- **Увеличение и сдвиг.** Колесо мыши увеличивает диаграмму в сторону курсора, до 200 раз; перетаскивание средней кнопкой мыши сдвигает её (см. [Клавиатура и мышь](#клавиатура-и-мышь)).
- **Контекстное меню.** Правая кнопка мыши открывает меню с пунктами **Открыть в Проводнике**, **Свойства**, **Копировать путь** и **Удалить…** для сектора под курсором, а при щелчке по центру — для текущего каталога; то же меню доступно в дереве каталогов и в списках файлов. `Ctrl+C` копирует полный путь элемента под курсором на диаграмме или в списке, а если курсор находится в другом месте — путь центра диаграммы.
- **Удаление.** **Удалить…** запрашивает подтверждение и перемещает элемент в корзину (для элемента, который нельзя поместить в корзину, Windows предупреждает об окончательном удалении); после этого диаграмма, дерево и списки обновляются без повторного сканирования. Сканируемую папку целиком удалить нельзя.
- **Повторное сканирование.** При повторном сканировании сохраняются текущая папка и история навигации, а прежние результаты остаются на экране до его завершения; если папка больше не существует, открывается ближайшая сохранившаяся родительская папка. При выборе другого диска или папки прежние результаты сразу убираются, а вместо них показывается индикатор с ходом сканирования.

### Боковая панель

Панель слева содержит четыре вкладки: **Папки**, **Крупные файлы**, **Поиск** и **Типы**.

- **Папки.** Дерево каталогов синхронизировано с диаграммой в обе стороны. При смене центра диаграммы раскрытыми остаются только папки на пути к нему. При движении мыши по диаграмме дерево временно раскрывается до элемента под курсором и сворачивается обратно, когда курсор находится на диаграмме вне секторов (при переходе мыши с диаграммы в дерево раскрытие сохраняется); флажок **Следить в дереве** на панели инструментов (включён по умолчанию) отключает это поведение. Кнопка **Свернуть все** над деревом сворачивает все папки, кроме просканированной; щелчок по файлу текущего центра снова раскрывает дерево до него.
- **Крупные файлы.** 100 самых больших файлов под центром диаграммы с указанием их папок. Наведение на строку подсвечивает файл на диаграмме, а щелчок переводит диаграмму в папку файла, где файл остаётся выделенным в списке. Список можно ограничить файлами, которые не изменялись больше одного, двух, пяти или десяти лет до сканирования (**Старше N лет**), что позволяет найти большие файлы, давно не использовавшиеся.
- **Поиск** (`Ctrl+F`). Файлы и папки всего скана, в имени которых встречается введённый текст, без учёта регистра; показываются 200 самых больших совпадений, их общее число и суммарный размер (файлы внутри совпавшей папки учитываются один раз), а совпавшие части имён подсвечиваются. Пока вкладка открыта, диаграмма сохраняет цвет совпадений и приглушает всё остальное; папка, содержащая совпадения, окрашивается по их доле в её размере, и эта доля показывается во всплывающей подсказке. Щелчок по папке делает её центром диаграммы, щелчок по файлу переводит в его папку. Синтаксис запросов описан [ниже](#синтаксис-поиска).
- **Типы.** Типы файлов (расширения без учёта регистра) в центре диаграммы с описанием, которое даёт им Windows, долей в центре и суммарным размером, начиная с самых больших; подсказка к строке добавляет число файлов и оба размера. Щелчок по типу выделяет его файлы на диаграмме и приглушает всё остальное, повторный щелчок снимает выделение; двойной щелчок показывает файлы этого типа во вкладке **Поиск** (`*.mp4`). Стрелка слева от типа раскрывает 20 самых больших его файлов в центре диаграммы с указанием папок; как и в других списках, наведение на файл обводит его на диаграмме, щелчок переводит диаграмму в его папку, а контекстное меню относится к нему. Если файлов этого типа больше, ссылка после них открывает все во вкладке **Поиск**.

Списки **Крупные файлы** и **Поиск** упорядочиваются по размеру (**Сначала большие**), по дате последнего изменения начиная со старых (**Сначала старые**) или начиная с новых (**Сначала новые**); при упорядочении по дате или фильтре по возрасту показывается столбец с датой. Подсказка к строке содержит полный путь и дату.

#### Синтаксис поиска

| Запрос | Что находит |
|---|---|
| `report 2024` | Имена, содержащие все слова, разделённые пробелами, в любом порядке. |
| `mp4\|mkv`, `*.mp4;*.mkv` | Альтернативы: слова, соединённые `;` или `\|`, связываются сильнее пробела. |
| `"big fish"` | Фразу, объединённую кавычками. |
| `*.py` | Маску для всего имени, как в Проводнике: `*` — любая последовательность символов, `?` — один символ. |
| `*.mp4;*.mkv 2010` | Файлы MP4 и MKV с 2010 в имени. |

Кнопка с листом и папкой переключает поиск между файлами и папками, только файлами и только папками. Кнопка **ab** в поле ограничивает поиск по тексту (без масок) целыми словами (так, `.py` находит `script.py`, но не `module.pyd`); состояние обеих кнопок сохраняется между запусками. Кнопка **×** или `Esc` очищает поле.

### Экспорт в CSV

Кнопка **Экспорт…** во вкладках **Папки**, **Крупные файлы** и **Поиск** сохраняет список в файл CSV:

| Вкладка | Содержимое | Столбцы |
|---|---|---|
| **Папки** | Папки дерева в том объёме, в каком они развёрнуты, поэтому отчёт нужной глубины получается, если сначала развернуть дерево. | `path`, `level` (глубина от просканированной папки), `size`, `allocated`, `files` и `folders` (число файлов и папок внутри), `modified` |
| **Крупные файлы** | Показанные файлы в выбранном порядке. | `path`, `type` (`file` или `folder`), `size` и `allocated` (в байтах), `modified` (местное время, `2024-03-15 14:02:11`) |
| **Поиск** | Все совпадения, а не только 200 показанных, в выбранном порядке. | те же, что для **Крупных файлов** |

Файл записывается в UTF-8 с меткой порядка байтов, чтобы Excel правильно читал имена не латиницей. Поля разделяются разделителем элементов списка из региональных настроек Windows, который Excel ожидает при открытии CSV (`;`, если десятичный разделитель — запятая). Те же списки доступны без окна через параметр [`--export`](#командная-строка).

### Интерфейс

- **Языки.** Интерфейс доступен на русском и английском языках. Язык следует языку Windows (русский, если Windows показывает интерфейс на русском, иначе английский) и выбирается в окне **О программе**; размеры, даты и числа следуют языку (`4,6 ГБ` и `15.03.2024` на русском, `4.6 GB` и `2024-03-15` на английском). Режимы командной строки выводят текст на английском.
- **Темы.** Светлая и тёмная темы переключаются кнопкой с солнцем, луной или наполовину закрашенным кругом рядом с кнопкой **О программе**: щелчок переходит от следования настройке Windows (по умолчанию) к светлой теме, затем к тёмной и обратно. Для каждой темы у диаграммы своя палитра; в тёмной цвета глубже и к краю уходят в фон.
- **Строка состояния.** Строка состояния показывает число каталогов и файлов, логический и физический размер и потери на округление для текущего корня.

### Настройки и портативный режим

Между запусками сохраняются: язык, тема, флажок проверки обновлений, метрика диаграммы, цветовая схема, число колец, флажок **Следить в дереве**, вкладка левой панели, порядок обоих списков и фильтр по возрасту во вкладке **Крупные файлы**, размер и положение окна, ширина дерева, а также последний просканированный путь, который подставляется в поле пути без запуска сканирования. При запуске в списке дисков ничего не выбрано, поэтому медленный или сетевой диск не сканируется без запроса.

Настройки хранятся в `%APPDATA%\Disk Flashlight\data\app.ron`. Копия программы становится портативной, если рядом с `disk_flashlight.exe` находится файл `disk_flashlight.ron` (достаточно пустого): настройки тогда хранятся в этом файле, и в профиль пользователя ничего не записывается. Если файл недоступен для записи, например на носителе только для чтения, используется профиль. Место хранения настроек указано в окне **О программе**. Если программа останавливается из-за внутренней ошибки, она сообщает об этом в окне сообщения и дописывает подробности в `crash.log` в той же папке.

### Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. Если в окне **О программе** включён флажок **Проверять обновления при запуске (раз в сутки)**, приложение не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** в том же окне запрашивает его сразу. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, справа от кнопки **О программе** появляется кнопка с его версией, которая открывает страницу выпуска в браузере. В остальном приложение обращается к сети только при сканировании сетевых дисков и путей.

## Использование

### Выбор объекта сканирования

- **Список дисков.** Помимо дисков, список дисков содержит восемь недавно просканированных папок (корни дисков в них не повторяются; пункт **Очистить список** очищает этот список, который сохраняется между запусками) и пункт **Выбрать папку…**, который открывает стандартный диалог выбора папки Windows и сканирует выбранную папку.
- **Перетаскивание.** Папку или диск можно перетащить из Проводника на окно программы; для перетащенного файла сканируется папка, в которой он находится. Когда программа запущена от имени администратора (после нажатия **Быстрый скан**), Windows не передаёт ей перетаскивание из Проводника, запущенного без повышенных прав.
- **Поле пути.** Путь можно ввести в поле справа на панели инструментов: оно показывает текущий путь и по щелчку становится редактируемым, как адресная строка Проводника. При вводе под полем предлагаются подходящие папки (или диски), стрелки выбирают вариант, `Tab` или `Enter` подставляет его, а `Enter` сканирует введённый путь; `Esc` отменяет ввод. О несуществующем пути или пути, не являющемся папкой, сообщается в строке состояния, а результаты на экране сохраняются.
- **Проводник.** При установленной дополнительной задаче установщика пункт **Анализировать в Disk Flashlight** в контекстном меню папки или диска открывает их в программе.

Версия программы указана в окне **О программе**.

### Клавиатура и мышь

| Клавиши | Действие |
|---|---|
| `Backspace` | На уровень выше (при выбранном секторе покинутая папка остаётся выбранной) |
| `Alt+Left`, `Alt+Right` | Назад и вперёд по истории |
| `F5` | Повторное сканирование |
| `Ctrl+F` | Поиск |
| `Ctrl+C` | Копирование пути элемента под курсором (или центра) |
| `+`, `-` | Добавление и удаление кольца |
| `F1` | Окно **О программе** (также доступно на панели инструментов) |
| `Right`, `Left` | Следующий или предыдущий сектор того же кольца (по часовой стрелке и обратно) |
| `Down` | Самый большой элемент внутри выбранной папки на следующем кольце |
| `Up` | Родительская папка на кольцо ближе к центру |
| `Enter` | Действует как щелчок: папка становится центром диаграммы, и в ней выбирается самый большой элемент, а для файла открывается его папка |
| `Delete` | Перемещение выбранного элемента (или элемента под курсором на диаграмме или в списке) в корзину после подтверждения |
| `Ctrl+E` | Открытие выбранного элемента в Проводнике (при отсутствии выбора — центра диаграммы) |
| `Esc` | Снятие выбора, сделанного с клавиатуры |

Первое нажатие стрелки начинает с элемента под курсором или с самого большого элемента. Выбранный сектор обводится и показывает подсказку, как при наведении мыши, пока мышь не сдвинется или не будет нажата `Esc`.

| Мышь | Действие |
|---|---|
| Щелчок по сектору | Папка становится центром; для файла открывается его папка; группа увеличивается |
| Щелчок по центру | На уровень выше |
| Правая кнопка | Контекстное меню |
| Колесо | Увеличение в сторону курсора |
| Перетаскивание средней кнопкой | Сдвиг |
| Двойной щелчок средней кнопкой | Возврат к исходному виду, как и небольшая кнопка с коэффициентом увеличения в правом верхнем углу диаграммы (видна при увеличении или сдвиге) |

### Командная строка

```
disk_flashlight.exe              # открывает окно; диск выбирается в панели инструментов
disk_flashlight.exe D:\Projects  # сканирует указанный путь при запуске
disk_flashlight.exe --bench C:\  # консольный бенчмарк сканера и раскладки
disk_flashlight.exe --bench C:\ --walk  # тот же бенчмарк с отключённым сканером MFT
disk_flashlight.exe --version    # выводит версию
disk_flashlight.exe --mft C:\    # перезапускается с правами администратора (запрос UAC) и сканирует C: через MFT
disk_flashlight.exe --export D:\ --out largest.csv                  # 100 самых больших файлов в CSV
disk_flashlight.exe --export D:\ --largest 500 --older-than 2 --out old.csv
disk_flashlight.exe --export C:\ --search "*.iso;*.vhdx" --sep ";" --out images.csv
```

Параметр `--mft` запрашивает права администратора только там, где они ускоряют сканирование: для диска или папки на локальном томе NTFS или при запуске без пути. Для другой файловой системы или сетевого пути, а также при отказе в запросе UAC программа запускается обычным образом и обходит каталоги.

Параметр `--export` сканирует путь так же, как `--bench`, и записывает список в формате кнопки **Экспорт…**, не открывая окно. Без `--out` CSV выводится в стандартный вывод; строка с итогом выводится в стандартный поток ошибок. `--help` перечисляет параметры.

| Параметр | Назначение |
|---|---|
| `--largest N` | N самых больших файлов (по умолчанию 100) |
| `--older-than Y` | Только файлы, не изменявшиеся Y лет (вместе с `--largest`) |
| `--search ЗАПРОС` | Все совпадения запроса в синтаксисе вкладки **Поиск** |
| `--kind files`, `--kind folders` | Ограничение поиска файлами или папками |
| `--whole-word` | Поиск целых слов |
| `--sort size\|oldest\|newest` | Порядок строк |
| `--logical` | Размеры по длине, а не по месту на диске |
| `--sep РАЗДЕЛИТЕЛЬ` | Разделитель полей (по умолчанию запятая, `tab` — табуляция) |
| `--out ФАЙЛ` | Выходной файл |
| `--walk` | Отключение сканера MFT |

При заданной переменной окружения `RUST_LOG=disk_flashlight=debug` выводятся замеры отдельных фаз сканера MFT.

## Сборка

Требования: стабильный toolchain Rust (MSVC) и Visual Studio Build Tools с компонентами C++.

```
cargo build --release
```

Исполняемый файл создаётся по пути `target\release\disk_flashlight.exe`.

<details>
<summary><b>Подготовка окружения</b></summary>

Проект собирается на Windows 10 или 11 (x64). Использовалось следующее; приведённые команды устанавливают всё через `winget`:

- **Visual Studio Build Tools 2022** с рабочей нагрузкой «Разработка классических приложений на C++» (`Microsoft.VisualStudio.Workload.VCTools`): компилятор и компоновщик MSVC v143 и Windows 11 SDK (10.0.26100). Компоновщик нужен Rust для цели MSVC, а `rc.exe` из SDK — сценарию сборки, который встраивает в исполняемый файл значок и сведения о версии (`winresource`). Build Tools устанавливаются без Visual Studio:

  ```
  winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
  ```

  Установщик `rustup-init.exe` при отсутствии Build Tools также предлагает их установить.

- **Rust** через `rustup`, toolchain `stable-x86_64-pc-windows-msvc` (проверено на 1.98). Проект использует редакцию 2024 и цепочки `if let`, поэтому требуется Rust 1.88 или новее.

  ```
  winget install Rustlang.Rustup
  rustup default stable-x86_64-pc-windows-msvc
  ```

- Только для установщика и выпуска: **Python 3** (проверено на 3.14; скрипт обходится стандартной библиотекой) и **Inno Setup 6**, чей `ISCC.exe` ищется в стандартных папках установки и в `PATH`.

  ```
  winget install Python.Python.3.14
  winget install JRSoftware.InnoSetup
  ```

Остальные зависимости (egui, wgpu, windows-sys и другие) загружает `cargo` при первой сборке.

</details>

### Установщик и выпуск

Скрипт выпуска собирает исполняемый файл и установщик для текущего пользователя (требуется Inno Setup 6):

```
python tools/make_release.py              # тесты, release-сборка, установщик
python tools/make_release.py --no-tests   # то же без cargo test
```

Установщик создаётся по пути `dist\Disk_Flashlight_<версия>_Setup.exe` вместе с портативным архивом `dist\Disk_Flashlight_<версия>_portable.zip` (см. [Загрузка](#загрузка)); версия берётся из `Cargo.toml`.

Выпуски на GitHub собираются workflow **Release** (`.github/workflows/release.yml`). После изменения версии в `Cargo.toml` и коммита отправка соответствующего тега публикует выпуск с установщиком и портативным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Если тег не совпадает с версией в `Cargo.toml`, workflow останавливается с ошибкой. Ручной запуск на вкладке Actions собирает те же файлы в виде артефакта без публикации выпуска.

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/model.rs` | Арена-дерево в порядке обхода в глубину, дети отсортированы по размеру; самые большие файлы и поиск по имени |
| `src/types.rs` | Типы файлов (расширения): итоги по папке и цветовые позиции |
| `src/scan/mft.rs` | Чтение и разбор главной файловой таблицы NTFS |
| `src/scan/walk.rs` | Параллельный обход каталогов (rayon поверх листингов каталогов, читаемых блоками по 64 КиБ) |
| `src/scan/win.rs` | Обёртки Win32: диски, листинг каталогов, размер кластера, размер сжатых файлов, корзина, Проводник |
| `src/layout.rs` | Раскладка секторов и определение попадания курсора |
| `src/render.rs` | Тесселяция секторов в `egui::Mesh`, палитры для обеих тем |
| `src/ui/` | Виджет диаграммы, дерево каталогов, вкладки «Крупные файлы», «Поиск» и «Типы», поле пути, панель инструментов и строка состояния, окна «О программе» и «Ошибки доступа» |
| `src/history.rs` | История навигации назад и вперёд |
| `src/settings.rs` | Настройки, сохраняемые между запусками, портативный режим |
| `src/i18n.rs`, `src/format.rs` | Английский и русский интерфейс; размеры, числа и даты на языке интерфейса |
| `tools/` | Сценарий установщика (`setup.iss`) и скрипт выпуска (`make_release.py`) |
